# 医学统计学学习助手

一款面向医学生、临床研究者和公共卫生学习者的本地桌面学习工具。它把医学统计学课程、方法选择、统计计算和病例练习放在同一个工作台中，帮助使用者从“记住检验名称”走向“理解研究设计并正确解释结果”。

> 当前版本以离线学习和本地计算为核心。学习记录、输入数据和论文片段不会上传到网络。

## 核心功能

- **系统课程**：15 章医学统计学内容，从描述性统计、概率与抽样一路覆盖回归、诊断试验和生存分析。
- **方法选择器**：根据研究目的、结局类型、组数、配对关系和分布特征推荐统计方法，同时给出适用条件、替代方案和论文表述。
- **统计计算器**：支持描述性统计、单样本 t 检验、Welch t 检验、四格表 χ² 检验和 Fisher 精确检验。
- **病例练习**：使用医学研究场景训练方法选择、P 值解释和临床意义判断，自动记录完成情况与错题。
- **论文阅读辅助**：从常见统计结果中识别 P 值、OR 和 95% CI，并给出规范解释。
- **学习进度**：在本机保存课程完成度、连续学习天数和模块掌握情况。
- **桌面体验**：基于 Tauri 打包为 Windows 应用，无需启动开发服务器。

## 设计原则

1. **先研究设计，后统计方法**：从研究目的和变量类型出发，而不是凭检验名称猜答案。
2. **效应量优先**：统计学显著不能替代临床意义，解释结果时同时关注效应量和置信区间。
3. **明确适用边界**：每种方法都展示前提条件、常见误区和替代方案。
4. **隐私优先**：计算和学习记录默认仅保存在本机，不上传患者数据。

## 安装

前往 [Releases](https://github.com/ctxedkbh1/medstats-learning-assistant/releases) 下载最新的 Windows 安装包，运行 `MedStats-Learning-Assistant-Setup.exe` 并按提示完成安装。

Windows 可能对未签名的新应用显示安全提示。请确认安装包来自本仓库 Release 页面，并按需核对 Release 中公布的 SHA-256。

## 本地开发

环境要求：

- Node.js 20 或更高版本
- Rust stable 工具链
- Visual Studio 2022 Build Tools（Desktop development with C++）
- Windows 10/11 SDK

```bash
npm install
npm run dev
```

运行测试与 Web 构建：

```bash
npm test
npm run build
```

构建 Windows 桌面安装包：

```bash
npm run build:exe
```

```text
src/
  data/          课程与练习内容
  lib/           统计计算和方法选择逻辑
  types/         领域类型定义
  App.tsx        应用页面与交互

tests/           统计计算和方法推荐测试
```

## 重要说明

本项目用于统计学教育和研究辅助，不构成医疗建议，也不能替代专业统计咨询。处理真实临床数据前，请移除姓名、住院号、身份证号等直接身份标识，并遵守所在机构的伦理、隐私和数据治理要求。
